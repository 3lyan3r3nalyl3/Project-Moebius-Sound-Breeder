# Project-Moebius-Sound-Breeder
A graphical procedural sound-breeding environment for Linux/Python.  This is not primarily a sound editor. It is a **sound genetics laboratory**: generate organisms, inspect their genomes, choose parents, breed descendants, cross unrelated families, and export sampler-ready WAV files.
